# Gesture-Controlled Robot Vehicle

A wireless gesture-controlled robot vehicle built using Arduino microcontrollers, a GY-61 accelerometer, nRF24L01 wireless transceivers, and an L298N motor driver.

The project explores embedded systems, wireless communication, electronics prototyping, and robotic control by translating hand gestures into real-time vehicle movement.

---

## Overview

This project consists of two independent systems:

- **Transmitter** – A glove-mounted controller using an Arduino Uno and GY-61 accelerometer to detect hand movement.
- **Receiver** – A four-wheel robot car using an Arduino Nano that receives wireless commands and controls four DC motors.

Communication between the two systems is achieved using nRF24L01 wireless modules operating at 2.4 GHz.

---

## Hardware

### Transmitter

- Arduino Uno
- GY-61 (ADXL335 Accelerometer)
- nRF24L01
- 9V Battery
- Zero PCB
- Velcro Glove

### Receiver

- Arduino Nano
- nRF24L01
- L298N Motor Driver
- 4 TT Gear Motors
- 4WD Chassis
- Dual 18650 Battery Pack
- Zero PCB
